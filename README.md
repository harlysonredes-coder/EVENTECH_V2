# EVENTECH V2

Sistema de gerenciamento de eventos desenvolvido em Python utilizando o framework FastAPI.

## Sobre o projeto

O EVENTECH V2 é uma API voltada ao gerenciamento de eventos, permitindo organizar usuários, eventos, inscrições, participações e certificados.

## Funcionalidades

- Cadastro e gerenciamento de usuários.
- Cadastro e gerenciamento de eventos.
- Controle de inscrições.
- Registro de participações.
- Gerenciamento de certificados.
- Autenticação de usuários com JWT.
- Documentação interativa utilizando Swagger UI.

## Tecnologias utilizadas

- Python
- FastAPI
- SQLAlchemy
- SQLite
- JWT

## Como executar

Instale as dependências necessárias do projeto e execute o comando:

`python -m uvicorn main:app --reload`

Depois, acesse a documentação interativa:

`http://127.0.0.1:8000/docs`

## Projeto acadêmico

Desenvolvido para a disciplina de Desenvolvimento Back-End, utilizando conceitos de APIs REST, banco de dados e autenticação.
